專案初始設定

下載node (版本 20.10.0)
https://nodejs.org/en

npm init
npm install express express ejs
npm install mongoose //mongodb資料庫套件
npm install method-override // use HTTP verbs such as PUT or DELETE in places where the client doesn't support it.
npm i cors
(以上一定要裝)
npm i express-session //session套件
npm i dotenv //獲得環境變數
npm i connect-flash //紀錄簡短訊息 例如登入成功與否
npm install readline //terminal可以讀取數值用(檢查數值用)
npm install socket.io//即時更新數值使用
npm install @line/bot-sdk //linebot
npm install dotenv //常用於載入環境變數，並在開發中常被用來管理敏感資訊，如 API 金鑰等。


設定app.js
node app.js 執行並確認有出現(伺服器正在聆聽 port 3000...)
